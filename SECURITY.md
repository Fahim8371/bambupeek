# Security

Only the latest preview is maintained. BambuPeek is intended for trusted local networks; see the [security model](docs/privacy.md), including self-signed printer TLS and local-storage limitations.

Use the repository’s **Security → Report a vulnerability** feature for a private report. Include a minimal reproduction using synthetic credentials. Do not attach real camera images, access codes, serial numbers, or raw network captures.

If private reporting is unavailable, open a public issue requesting a private reporting channel without disclosing vulnerability details or private data.

Security reports are reviewed on a best-effort basis; there is no guaranteed response time.
